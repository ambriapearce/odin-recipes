# odin-recipes

## A project written in HTML showing how to build a basic website!

This project is an example that was built following The Odin Project HTML Foundations roadmap. This project shows how to do the following:

* Create and HTML file.
* Create a HTML boilerplate.
* Build the body of the webpage.
* Link to other HTML pages using relative file paths.
* Add images.
